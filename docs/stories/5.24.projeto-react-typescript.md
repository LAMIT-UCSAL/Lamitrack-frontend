## Story

**Como** pessoa desenvolvedora do LamiTrack,
**quero** um projeto React + TypeScript na raiz do repositório, que rode com um comando e seja verificado pelo CI,
**para que** as tarefas de porte (#3, #13–#18) e de telas (#4, #5, #20) possam começar sobre uma base comum e testada.

## Acceptance Criteria

1. **Roda local com um comando.** Numa cópia limpa do repositório, `npm install && npm run dev` sobe o app e a rota `/` responde com uma página renderizada no servidor (SSR). [Fonte: issue #2, "Pronto quando"]
2. **Stack conforme a decisão registrada na #2:** React Router em modo framework (SSR) + Vite + TypeScript; Vitest + Testing Library para testes unitários; ESLint + Prettier; Bootstrap 5 (só CSS) + SCSS. [Fonte: comentário de decisão de stack na #2]
3. **Scripts padronizados** no `package.json` da raiz: `dev`, `build`, `start`, `lint`, `typecheck`, `test` (sem modo watch) e `format`. Os quatro primeiros gates (`lint`, `typecheck`, `test`, `build`) passam sem erro.
4. **Existe pelo menos um teste unitário real**, de um componente renderizado com Testing Library, e ele passa com `npm test`.
5. **O build passa no CI.** O workflow `.github/workflows/ci.yml` executa, num PR, `lint`, `typecheck`, `test` e `build` de verdade (não apenas `--if-present` sem scripts). [Fonte: issue #2, "Pronto quando"]
6. **Nada existente é apagado:** `README.md`, `LICENSE`, `CONTRIBUTING.md`, `netlify.toml`, `.github/` e a pasta `eve/` continuam no repositório. O `package.json` da raiz é **mesclado** com o do scaffold, e a dependência `playwright` é mantida. [Fonte: issue #2, "Cuidado ao criar o projeto"]
7. **`eve/` fica fora das ferramentas do projeto novo:** ESLint, TypeScript e Vitest não analisam nem executam nada dentro de `eve/`.
8. **`node_modules/` sai do git:** os arquivos de `node_modules/` hoje versionados na raiz são removidos do índice (`git rm -r --cached`), e o `.gitignore` da raiz passa a ignorar `node_modules/`, a saída de build, o cache de tipos do React Router e arquivos `.env`.
9. **O `README.md` da raiz** explica como rodar o projeto (pré-requisito de versão do Node, instalar, `dev`, `test`, `build`).

## Dependências

- Nenhuma story anterior. Esta é a primeira story de código do front.
- Pré-requisito de ambiente: Node ≥ 22.22 (exigido pelo `@react-router/dev` 8.x). O CI usa `lts/*`, que atende.

## Riscos

- **Versão do React Router:** o comentário de decisão na #2 cita "v7", mas a versão atual é a 8.4. O modo framework, `loader` e `meta` são as APIs que a decisão pressupõe; @dev deve confirmar no template oficial da v8 que elas existem como descrito e registrar qualquer diferença no decision log.
- **TypeScript:** o template oficial fixa `typescript ^5.9.3` (verificado pelo @po). Usar essa versão; não subir para a 7 nesta story.
- **Repositório no OneDrive:** instalar `node_modules` numa pasta sincronizada pelo OneDrive é lento e pode travar arquivos (já aconteceu nesta sessão). Não afeta o código, mas pode afetar o tempo de execução local.
- **Mescla do `package.json`:** o `package-lock.json` da raiz também será regenerado; conferir que o `npm ci` do CI continua funcionando com ele.

Preferir as versões que o template oficial gerar; as demais, instalar na versão atual.

**Variáveis de ambiente:** nenhuma nesta story. A URL da API do backend só entra com a #4/#5.

**SSR (renderização no servidor):** o HTML da página é montado no servidor Node antes de chegar ao navegador. É o motivo da escolha do modo framework: o WhatsApp não executa JavaScript ao gerar a prévia de um link, então as meta tags de cada evento precisam vir no HTML (isso será usado na #5, não nesta story).

**Identidade visual:** a referência é `eve/CLAUDE.md` (seção "Identidade visual", tabela de tokens e as 5 categorias de badge) e `eve/src/styles.scss`. As únicas 5 categorias válidas são Hackathon, Ideathon, Maratona, Edital e Eventos de Inovação.

**Protótipo como referência:** o `eve/` builda (`ng build`) e passa nos 57 testes unitários (`npm run test:ci`). O `npm audit` dele aponta vulnerabilidades do Angular 18; ele não deve ir para produção nem ser atualizado nesta story.
